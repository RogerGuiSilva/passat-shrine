
# Passat Shrine 

Catálogo interativo com a linha histórica do Volkswagen Passat (1973–2024), desenvolvido em React. O usuário pode navegar entre os modelos, ver detalhes técnicos, favoritar carros e deixar comentários em cada modelo.

## Funcionalidades

- Catálogo com todos os modelos do Passat, do B1 ao B9
- Página de detalhes com especificações técnicas de cada carro
- Sistema de favoritos (adicionar/remover)
- Formulário de comentários por modelo, com cadastro em tempo real (`useState`)
- Navegação entre páginas com React Router

## Tecnologias utilizadas

- React 19
- React Router DOM
- Vite
- CSS

## Como rodar o projeto

Pré-requisitos: ter o [Node.js](https://nodejs.org/) instalado (versão 18 ou superior).

1. Clone o repositório:
```bash
git clone https://github.com/RogerGuiSilva/passat-shrine.git
```

2. Entre na pasta do projeto:
```bash
cd passat-shrine
```

3. Instale as dependências:
```bash
npm install
```

4. Rode o projeto em modo de desenvolvimento:
```bash
npm run dev
```

5. Abra no navegador o endereço que aparecer no terminal (geralmente `http://localhost:5173`).
